# 💰 Личные Финансы (1С:Предприятие 8.3)

Учебная/персональная конфигурация на платформе **«1С:Предприятие 8.3»**, предназначенная для ведения учета персональных денежных средств, оперативного контроля баланса на счетах и наглядного анализа структуры доходов и расходов.

---

## 📌 Ключевые возможности

* **Мультивалютный учет:** фиксация остатков и операций в произвольных валютах.
* **Учет мест хранения средств:** разделение финансов по типам кошельков (наличные, дебетовые карты, депозиты, инвестиционные счета).
* **Детализированная аналитика:** классификация всех поступлений и трат по иерархическим статьям доходов и расходов.
* **Аналитическая отчетность:**
  * Контроль актуальных остатков денег на счетах.
  * Анализ распределения расходов и доходов по категориям за период.
* **Удобное рабочее место:** обработка *Журнал доходов и расходов* для быстрого ввода и сквозного просмотра финансовой активности.

---

## 🛠 Архитектура и структура метаданных

Конфигурация построена на базе ключевых объектов платформы:

### 📁 Справочники
* **`Кошельки`** — места хранения денежных средств (наличные, банковские карты, накопительные счета).
* **`Валюты`** — справочник используемых валют с возможностью ведения курсов.
* **`СтатьяДоходов`** — категории поступлений (заработная плата, премии, инвестиции, подарки и пр.).
* **`СтатьяРасходов`** — категории списаний (продукты питания, аренда, коммунальные услуги, развлечения).

### 📄 Документы
* **`Доход`** — оформление поступления денег на целевой кошелек с привязкой к статье дохода.
* **`Расход`** — списание средств с выбранного кошелька с указанием статьи расхода.

### 📊 Отчеты
* **`ОстаткиНаСчетах`** — оперативная сводка по текущему наличию денежных средств в разрезе кошельков и валют.
* **`ДеньгиКатегории`** — структура расходов и доходов за выбранный временной интервал в разрезе статей.

### ⚙️ Обработки
* **`ЖурналДоходовИРасходов`** — единая рабочая панель пользователя для быстрого ввода операций и просмотра истории проводок.

### 📈 Регистры (рекомендуемая реализация)
* **Регистры накопления:**
  * *ОстаткиДенежныхСредств* (вид: Остатки) — измерения: `Кошелек`, `Валюта`; ресурс: `Сумма`.
  * *ДоходыИРасходы* (вид: Обороты) — измерения: `Статья`, `Валюта`; ресурс: `Сумма`.

## 🚀 Установка и развертывание

### Вариант 1. Загрузка из файла поставки (`.cf`)
1. Склонируйте репозиторий:
   ```bash
   git clone https://github.com/<ваш-логин>/<имя-репозитория>.git
   ```
2. Запустите платформу **«1С:Предприятие 8.3»** и добавьте новую чистую базу.
3. Откройте базу в режиме **Конфигуратор**.
4. В верхнем меню выберите: `Конфигурация` → `Открыть конфигурацию`.
5. Перейдите в: `Конфигурация` → `Загрузить конфигурацию из файла...` и укажите файл `1Cv8.cf`.
6. Нажмите **F7** (или `Конфигурация` → `Обновить конфигурацию базы данных`).
7. Запустите приложение в пользовательском режиме (**F5**).

### Вариант 2. Загрузка из исходных кодов (XML / выгрузка конфигурации)
1. В Конфигураторе откройте пункт меню `Конфигурация` → `Загрузить конфигурацию из файлов...`.
2. Укажите путь к каталогу с выгруженными XML-исходниками.
3. Примените изменения по клавише **F7**.
